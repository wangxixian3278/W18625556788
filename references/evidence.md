# Evidence and reporting rules

Every major conclusion should answer:

1. What data supports this?
2. Which platform(s) and time window?
3. How large was the sample?
4. Is this a platform-returned fact, a calculated metric, or an analytical inference?
5. What could make the conclusion wrong?

Use labels when helpful:

- **Observed** — directly returned public data
- **Calculated** — derived from observed fields
- **Inferred** — analytical interpretation
- **Hypothesis** — plausible opportunity needing more validation

Do not fabricate missing counts or infer unavailable fields.
